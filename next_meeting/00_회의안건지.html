4. 스마트태그 MPU6050 + 상태 RGB LED는 정함 — 나머지

4-1상태 LED의 위치 · 핀 · 색 규칙. 덮개 위에 붙여 보니 별로였다(덮개의 LED 구멍은 그대로) (예: 차체 상태 작업 중 · 정상 · 보류)위치
색
4-2MPU6050으로 무엇을 알리나. 제안: 충격이면 라인을 세우지 않고 차체만 '보류', 검사에서 판정. 문턱값은 교육장에서 잰다충격기울어짐실제 정지
4-3버튼을 두나 · 태그 ID. 버튼 = 작업자가 차체에서 직접 이상 신고. ID는 키태그 번호 / ESP32 고유번호(MAC)버튼 둠안 둠
ID 키태그MAC
4-4예비 태그를 만드나. 만들면 ESP32가 공정 4 + 태그 2 = 6개. 보유 4개라 2개 구매만듦안 만듦
4-5배터리. 개발은 USB. 쓸지, 언제 살지. 후보: 3.3V 변환기(S7V8F3, 해외 배송) + 충전 모듈 + 500mAh LiPo. 납땜을 도와줄 사람씀나중에 주문
납땜
