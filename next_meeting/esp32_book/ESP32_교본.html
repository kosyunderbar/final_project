ESP32 교본

읽고, 여덟 가지 실습을 해 보면 프로젝트의 통신 모뎀과 스마트태그를 바로 만들 수 있게 썼습니다. 예시는 모두 우리 공장 라인의 것입니다.

1 왜 쓰나2 보드 둘러보기3 첫 업로드4 핀과 loop5 시리얼과 한 줄6 Wi-Fi와 MQTT7 끊김과 저장8 프로젝트에 쓰기실습막혔을 때한 장 요약자가 점검
먼저 알아 둘 것. 아래 코드는 Mac에서 로직 시험만 통과했고, 실제 보드에 올려 보지는 못했습니다. 실습 0에서 처음 올릴 때 확인하게 됩니다. 확인하지 못한 항목은 맨 아래에 모아 두었습니다.
1

ESP32가 무엇이고, 우리 프로젝트에서 무슨 일을 하나

읽고 나면: ESP32 다섯 대가 각각 무엇을 맡는지 그림 한 장으로 설명할 수 있다.

ESP32는 Wi-Fi가 달린 손가락만 한 컴퓨터입니다. 운영체제 없이 우리가 올린 프로그램 하나만 켜지자마자 돌립니다. 핀으로 전기 신호를 읽고 쓰고, Wi-Fi로 메시지를 주고받습니다.

우리가 쓰는 이유는 하나입니다. 공정 보드(STM32)에는 Wi-Fi가 없습니다. 그래서 공정마다 ESP32를 옆에 붙여, 보드가 선으로 넘긴 한 줄을 관제 Pi5에 무선으로 전해 줍니다. 차체에 붙는 스마트태그도 ESP32입니다.

모뎀 ESP32는 줄을 받아 토픽으로 옮기고, 토픽으로 온 메시지를 줄로 바꿔 보드에 넘깁니다. 내용을 보고 판단하는 일은 하지 않습니다.
무엇수량하는 일
공정 통신 모뎀4P1~P4 공정 보드 옆. 선(UART) ↔ Wi-Fi(MQTT). 네 대가 같은 코드이고 공정 이름만 다릅니다
스마트태그1차체에 부착. 관제가 보내는 이력 사본을 받아 저장하고, 불빛과 버튼이 있습니다
단독 공정 미정0~2보드 구성 B′안을 고르면 일부 공정은 ESP32 혼자 리더기와 설비까지 맡습니다. 메시지는 같습니다

이 교본에서 다루지 않는 것: 블루투스, 절전, 무선 업데이트, ESP-IDF, FreeRTOS 내부. 4주 안에 쓸 일이 없습니다. 납땜도 여기서는 하지 않고 점퍼선만 씁니다.

보드 둘러보기

읽고 나면: USB, 버튼 두 개, 안테나, 전원 핀을 짚을 수 있고, 써도 되는 핀과 안 되는 핀을 말할 수 있다.

끌어서 돌리고, 부품을 누르면 설명이 나옵니다. 부품 위치는 대략이며 보드마다 조금 다릅니다.

핀 지도

양쪽에 19개씩, 모두 38개입니다. 핀을 누르면 이유와 우리 프로젝트에서의 쓰임이 나옵니다. 배선할 때는 그림 위치가 아니라 보드에 인쇄된 글자를 보고 꽂으세요. 한쪽이 15개인 30핀 보드는 순서가 다릅니다.

써도 됨조심쓰지 않음전원금색 글자 = 프로젝트 배정
1~14번 줄은 자료로 확인했고, 15~19번 줄은 같은 계열 보드의 배열입니다. 실물 글자로 확인하세요.

먼저 쓸 핀

16 17 18 19 21 22 23 25 26 27 32 33 13 4

아날로그 입력은 32~39만(Wi-Fi를 쓰는 동안 나머지 아날로그 핀은 못 읽습니다).

건드리지 않을 핀

0 2 5 12 15 · 6~11 · 1 3

부팅 방식을 정하는 핀, 내부 저장장치에 묶인 핀, USB와 같이 쓰는 핀입니다. 여기에 뭔가 달면 부팅이나 업로드가 안 됩니다.

전압 세 가지만 기억하세요. ① 핀은 3.3V까지입니다. 5V를 넣으면 망가집니다. ② 핀 하나로 모터·서보·부저를 직접 돌리지 않습니다. ③ 배선은 USB를 뽑고 바꿉니다. 3V3과 GND가 닿으면 보드나 Mac 포트가 죽을 수 있습니다.
3

개발 환경과 첫 업로드 (Mac)

읽고 나면: 포트를 찾아 프로그램을 올리고, 업로드가 안 될 때 스스로 풀 수 있다.

  1. Arduino IDE 2를 설치합니다. Settings의 Additional boards manager URLs에 아래 주소를 넣습니다. 
    https://espressif.github.io/arduino-esp32/package_esp32_index.json
  2. Boards Manager에서 esp32 by Espressif Systems를 설치합니다. 버전은 3.3.x로 고르세요. 4.0이 며칠 전에 나왔는데 우리가 쓰는 라이브러리와 맞는지 아직 모릅니다.
  3. Library Manager에서 PubSubClient(Nick O'Leary)와 ArduinoJson(Benoit Blanchon, 7.x)을 설치합니다.
  4. Tools → Board → esp32 → NodeMCU-32S. 없으면 ESP32 Dev Module.
  5. 보드를 USB로 꽂고 Tools → Port에서 /dev/cu.usbserial-… 또는 /dev/cu.SLAB_USBtoUART를 고릅니다. 터미널에서 ls /dev/cu.*를 꽂기 전후로 쳐서 새로 생긴 이름이 그 포트입니다.
  6. Serial Monitor는 115200, 줄 끝은 New Line으로 둡니다.
업로드가 안 될 때, 이 순서로. ① 케이블을 바꿉니다(충전 전용 케이블이면 포트가 아예 안 뜹니다. 가장 흔한 원인). ② Serial Monitor를 닫습니다. ③ BOOT 버튼을 누른 채 업로드를 시작하고 "Writing"이 보이면 뗍니다. ④ 핀 0·2·12·15에 꽂은 선을 뺍니다. ⑤ Upload Speed를 115200으로 낮춥니다.

EN 버튼은 다시 시작(리셋)입니다. 올린 프로그램은 지워지지 않습니다.

4

핀 읽고 쓰기, 그리고 멈추지 않는 loop

읽고 나면: delay 없이 불빛을 깜빡이면서 버튼의 짧게·길게 누름을 구분할 수 있다.

핀(GPIO)

전압으로 읽고 쓰는 참·거짓 변수입니다. 3.3V가 참, 0V가 거짓.

풀업

아무도 안 건드릴 때의 기본값입니다. 없으면 초기화 안 한 변수처럼 값이 떠돕니다. 그래서 버튼은 눌렀을 때 LOW입니다.

setup과 loop

setup은 켜질 때 한 번, loop는 끝없이 반복됩니다. 이벤트 루프와 같습니다.

delay를 쓰면

프로그램 전체가 잠듭니다. 그동안 버튼도, 선으로 오는 글자도, Wi-Fi도 놓칩니다.

스마트태그의 배정입니다(불빛 IO25, 버튼 IO33). 부품이 없으면 보드의 내장 LED(IO2)와 BOOT 버튼(IO0)으로 연습할 수 있습니다.
// delay 대신: "지난번 이후 얼마나 지났나"만 본다
static uint32_t last = 0;
if (millis() - last >= 500) {        // 0.5초마다
  last = millis();
  digitalWrite(25, !digitalRead(25)); // 불빛 뒤집기
}

// 버튼: 눌림 = LOW. 30ms 동안 같은 값이면 진짜로 본다(떨림 거르기)
pinMode(33, INPUT_PULLUP);
bool pressed = digitalRead(33) == LOW;

우리 라인에서 이게 왜 중요한가: 이상이 났을 때 버튼을 짧게 누르면 '봤다', 2초 누르면 '해제'입니다. 누르는 시간을 재려면 프로그램이 멈추지 않아야 합니다.

5

시리얼 두 개와 우리의 한 줄 규격

읽고 나면: $…*XX 줄을 읽고, 검사값을 확인하고, 직접 만들 수 있다.

UART는 선 두 가닥으로 글자를 차례로 보내는 통신입니다. ESP32에는 여러 개가 있고, 우리는 두 개를 씁니다.

이름핀어디로쓰임
Serial1, 3USB를 거쳐 Mac업로드와 로그. 다른 데 쓰지 않습니다
Serial2RX 16, TX 17공정 보드한 줄 규격으로 주고받기
핀 번호를 꼭 직접 적으세요. 새 버전(3.x)에서 Serial2의 기본 핀이 바뀌었습니다. 인터넷 예제처럼 Serial2.begin(115200)만 쓰면 16·17이 아닌 다른 핀으로 나갑니다. 
Serial2.begin(115200, SERIAL_8N1, 16, 17);   // RX=16, TX=17
TX는 상대의 RX로 갑니다(교차). 둘 다 3.3V라 바로 이어도 됩니다. NUCLEO의 USART2는 PC 연결에 묶여 있어 USART1을 씁니다. NUCLEO 쪽 핀 위치는 보드 설명서 그림으로 한 번 확인하세요.

한 줄의 모양

$R{"n":42,"k":"DONE"}*7B
$ 와 *시작과 끝 표시
종류 한 글자보드 → ESP32: T 태그 읽음, R 신고, H 살아 있음. ESP32 → 보드: C 답, S 지금 상태, L 연결 상태, X 시험 입력
내용보드가 보내는 것은 JSON 그대로. 보드가 받는 것은 이름=값을 쉼표로 이은 것(보드가 JSON을 풀지 않아도 되게)
검사값 2자리$ 와 * 사이의 모든 글자(종류 글자 포함)를 XOR한 값을 16진수 두 자리로. 선에서 글자가 깨졌는지 알아냅니다

검사값 계산기

문서나 메신저에서 복사하면 따옴표가 둥근 모양(“ ”)으로 바뀌어 검사값이 틀려집니다. 그럴 때는 직접 치세요.
6

Wi-Fi와 MQTT

읽고 나면: 브로커에 붙어 메시지를 보내고 받고, '보관'과 '유언'을 쓸 수 있다.

브로커와 토픽

우체국과 주소입니다. 보내는 쪽은 주소(토픽)에 붙이기만 하고, 누가 받는지 모릅니다. 받는 쪽은 주소를 구독합니다.

보관 (retained)

게시판에 붙여 둔 마지막 쪽지입니다. 늦게 온 구독자도 붙자마자 봅니다. 우리의 '지금 상태'와 '연결 상태'가 이것입니다.

유언 (LWT)

브로커에 미리 맡겨 둔 메시지입니다. 내가 말없이 사라지면 브로커가 대신 붙입니다. "이 공정 끊김"을 이것으로 알립니다.

Wi-Fi는 2.4GHz만

ESP32는 5GHz에 붙지 못합니다. 학교 인증 Wi-Fi도 안 됩니다. 전용 공유기나 휴대폰 핫스팟(2.4GHz)을 씁니다.

공정 이름만 바꾸면 네 공정이 모두 같습니다. 스마트태그는 factory/tag/{이름}/cmd · report · link를 씁니다.
// 연결 → 구독 → loop()를 계속 부른다. 다시 연결되면 구독도 다시 한다
mqtt.setServer(MQTT_HOST, 1883);
mqtt.setCallback(onMqtt);
mqtt.setBufferSize(512);                 // 기본 256바이트는 모자란다
mqtt.setKeepAlive(4);                    // 말없이 죽으면 약 6초 뒤 유언이 나간다

// 유언: 내가 죽으면 link=0(보관). 붙자마자 내가 link=1(보관)
if (mqtt.connect("modem-P2", "factory/station/P2/link", 0, true, "0")) {
  mqtt.publish("factory/station/P2/link", "1", true);
  mqtt.subscribe("factory/station/P2/cmd");
  mqtt.subscribe("factory/station/P2/state");
}
mqtt.loop();                             // 이게 없으면 받은 메시지가 처리되지 않는다

void onMqtt(char *topic, byte *payload, unsigned int len) {
  // payload는 문자열 끝 표시(0)가 없다. 반드시 len만큼만 읽는다
}

Mac을 브로커로 쓰기 (집에서)

brew install mosquitto

brew services restart mosquitto

설정 두 줄이 없으면 mosquitto는 자기 컴퓨터에서 온 연결만 받습니다. ESP32가 붙지 못하는 가장 흔한 이유입니다. Mac이 방화벽 허용을 물으면 허용하세요.

보드마다 이름(client ID)을 다르게 하세요. 같은 이름 두 대가 붙으면 브로커가 먼저 온 쪽을 끊어서, 서로 번갈아 끊깁니다.

7

끊김과 복구, 그리고 꺼져도 남는 저장

읽고 나면: 끊겨도 스스로 다시 붙게 만들고, 전원이 꺼져도 값을 남길 수 있다.

영상으로 찍을 장면이 바로 이것입니다. 밀린 신고를 쥐고 다시 보내는 일은 공정 보드가 하고, 모뎀은 연결을 되살리는 일만 합니다.

왜 바로 0이 안 되나. 전원이 뽑히면 "끊는다"는 말을 못 합니다. 브로커는 약속한 시간(keepalive)의 1.5배 동안 소식이 없어야 유언을 붙입니다. 4초로 두면 약 6초입니다.

다시 붙는 코드는 loop 안에 있어야 합니다. setup에서 한 번만 연결하면 끊긴 뒤 영영 돌아오지 않습니다. 기다릴 때도 while로 붙잡지 말고 millis()로 3초마다 한 번씩만 시도합니다.

#include <Preferences.h>
Preferences nv;
nv.begin("tag", false);                  // 이름표 "tag" (15자 이하)
uint32_t seq = nv.getUInt("seq", 0);     // 없으면 0
nv.putUInt("seq", 1042);                 // 전원이 꺼져도 남는다

저장장치(플래시)는 작은 SSD입니다. 꺼져도 남지만 쓰는 횟수에 한계가 있습니다. 값이 바뀔 때만 쓰고, loop에서 매번 쓰지 않습니다. 스마트태그가 이력 사본을 이렇게 저장합니다.

재부팅을 되풀이하면서 "Brownout"이 찍힌다면 전기가 모자란 것입니다. Wi-Fi를 켜는 순간 전류가 크게 튑니다. 짧은 케이블을 Mac에 직접 꽂고, 서보 같은 부품은 다른 전원에서 먹입니다.

8

프로젝트에 바로 쓰기

읽고 나면: 모뎀과 태그 코드를 자기 공정 이름으로 바꿔 올릴 수 있다.

코드는 next_meeting/esp32_book/code/에 있습니다. 스케치 폴더마다 secrets.example.h를 secrets.h로 복사해 Wi-Fi 이름, 비밀번호, 브로커 IP를 채웁니다. secrets.h는 git에 올리지 않습니다.

바꿀 곳모뎀스마트태그
이름#define STATION "P2"#define TAG_NAME "tag1"
핀RX 16, TX 17 그대로불빛과 버튼. 연습은 내장 LED(2)와 BOOT(0), 실물은 25와 33
시험 방식TEST_MODE 1: 공정 보드 없이 Serial Monitor가 보드 역할
TEST_MODE 2: 17→16을 점퍼로 이어 선 자체를 확인
0: 실제 사용		BOOT 버튼 짧게 = 신고 한 번, 길게 = 저장된 이력 출력 (둘 다 예시 동작)
모뎀 코드 전체 (modem.ino)
// modem.ino — 공정 통신 모뎀: 공정보드 UART <-> MQTT
// 대상: Arduino-ESP32 3.x / PubSubClient 2.8 / ArduinoJson 7
#include <WiFi.h>
#include <PubSubClient.h>
#include <ArduinoJson.h>
#include "secrets.h"             // WIFI_SSID, WIFI_PASS, MQTT_HOST, MQTT_PORT

// ───── 설정: 보드마다 STATION만 바꾼다 ─────
#define STATION        "P2" 
#define TEST_MODE      0         // 0 실사용 | 1 USB 시리얼 모니터가 공정보드 역할 | 2 TX2→RX2 점퍼 루프백
#define PIN_RX2        16        // 코어 3.x는 Serial2 기본 핀이 4/25로 바뀌었다 → 반드시 직접 지정
#define PIN_TX2        17
#define LINE_CAP       240       // '$'부터 체크섬까지 한 줄 최대 길이
#define MQTT_BUF       512       // PubSubClient 버퍼 (기본 256은 부족)
#define LINK_REPEAT_MS 2000      // $L(연결 상태)을 2초마다 보드에 알린다. 보드는 5초 동안 못 받으면 끊김으로 본다

#define BASE "factory/station/" STATION "/"
#if TEST_MODE == 1
  #define BOARD Serial           // USB로 줄을 직접 타이핑
#else
  #define BOARD Serial2
#endif
#define DBG(...) Serial.printf(__VA_ARGS__)   // 디버그는 항상 USB, '#'으로 시작

WiFiClient   net;
PubSubClient mqtt(net);

// ───── 체크섬 / 보드로 한 줄 보내기 ─────
uint8_t xorOf(const char *p, size_t n) { uint8_t c = 0; while (n--) c ^= (uint8_t)*p++; return c; }

void sendToBoard(const char *body) {          // body = 종류 글자 + 내용, 예: "C,re=42,ok=1"
  BOARD.printf("$%s*%02X\n", body, xorOf(body, strlen(body)));
  DBG("# ->board $%s\n", body);
}

// ───── 보드 → MQTT ─────
void handleLine(char *line, size_t len) {     // line = "$...*HH" (개행 제거됨)
  if (len < 5 || line[0] != '$' || line[len - 3] != '*') { DBG("# 형식 오류: %s\n", line); return; }
  char *end;
  uint8_t want = (uint8_t)strtoul(line + len - 2, &end, 16);
  if (end != line + len || xorOf(line + 1, len - 4) != want) { DBG("# 체크섬 오류: %s\n", line); return; }

  char type = line[1];
  const uint8_t *payload = (const uint8_t *)line + 2;   // 종류 글자 다음부터 '*' 앞까지
  size_t plen = len - 5;
  const char *topic = type == 'T' ? BASE "tag" : type == 'R' ? BASE "report" : type == 'H' ? BASE "alive" : nullptr;
  if (!topic) { DBG(TEST_MODE == 2 ? "# 루프백 OK: %s\n" : "# 모르는 종류: %s\n", line); return; }
  if (!mqtt.connected()) { DBG("# 링크 없음, 버림 (보드가 재전송)\n"); return; }
  bool ok = mqtt.publish(topic, payload, plen, false);  // JSON을 그대로, QoS 0
  DBG("# ->mqtt %s %s\n", topic, ok ? "ok" : "실패(버퍼 초과?)");
}

void pollBoard() {                            // 한 글자씩 모아서 '\n'에서 한 줄 완성. 절대 기다리지 않는다
  static char buf[LINE_CAP + 1];
  static size_t n = 0;
  static bool over = false;
  while (BOARD.available()) {
    char c = (char)BOARD.read();
    if (c == '\r') continue;
    if (c == '\n') {
      if (over) DBG("# 줄이 너무 김, 버림\n");
      else if (n) { buf[n] = 0; handleLine(buf, n); }
      n = 0; over = false;
    } else if (n < LINE_CAP) buf[n++] = c;
    else over = true;                         // 길이 초과: 다음 '\n'까지 통째로 버린다
  }
}

// ───── MQTT → 보드: JSON {"re":42,"ok":1} → "$C,re=42,ok=1*67" ─────
void onMqtt(char *topic, byte *payload, unsigned int len) {
  if (strncmp(topic, BASE, strlen(BASE)) != 0) return;
  const char *leaf = topic + strlen(BASE);
  char type = !strcmp(leaf, "cmd") ? 'C' : !strcmp(leaf, "state") ? 'S' : !strcmp(leaf, "test") ? 'X' : 0;
  if (!type) return;

  JsonDocument doc;                           // payload는 0으로 끝나지 않는다 → 길이를 꼭 넘긴다
  DeserializationError err = deserializeJson(doc, (const char *)payload, len);
  JsonObject obj = doc.as<JsonObject>();
  if (err || obj.isNull()) { DBG("# JSON 오류(%s): %s\n", leaf, err.c_str()); return; }

  char body[LINE_CAP - 3];
  size_t n = 0;
  body[n++] = type; body[n] = 0;
  for (JsonPair kv : obj) {                   // 보낸 순서 그대로 나온다
    const char *k = kv.key().c_str();
    if (type == 'S' && !strcmp(k, "body")) continue;      // state의 body는 보드에 안 보낸다
    char val[48];
    JsonVariant v = kv.value();
    if (v.is<JsonObject>() || v.is<JsonArray>()) { DBG("# 중첩 값 거부: %s\n", k); return; }
    size_t vl = v.is<const char *>() ? strlcpy(val, v.as<const char *>(), sizeof val)
                                     : serializeJson(v, val, sizeof val);   // 숫자는 글자로
    if (vl >= sizeof val || strpbrk(k, ",=*$\r\n") || strpbrk(val, ",=*$\r\n")) { DBG("# 값 거부: %s\n", k); return; }
    int w = snprintf(body + n, sizeof body - n, ",%s=%s", k, val);
    if (w < 0 || (size_t)w >= sizeof body - n) { DBG("# 줄 길이 초과\n"); return; }
    n += w;
  }
  sendToBoard(body);
}

// ───── Wi-Fi / MQTT 유지 (loop에서 계속 호출, 기다리지 않음) ─────
void serviceWifi() {
  static uint32_t lastTry = 0;
  static bool was = false;
  bool ok = WiFi.status() == WL_CONNECTED;
  if (ok && !was) DBG("# WiFi 연결 %s\n", WiFi.localIP().toString().c_str());
  if (!ok && was) DBG("# WiFi 끊김\n");
  was = ok;
  if (!ok && millis() - lastTry >= 15000) {   // 15초마다 처음부터 다시 시도
    lastTry = millis();
    WiFi.disconnect();
    WiFi.begin(WIFI_SSID, WIFI_PASS);
  }
}

void serviceMqtt() {
  static bool wasUp = false;
  static uint32_t lastTry = 0, lastLink = 0;
  bool up = mqtt.connected();
  if (up) {
    mqtt.loop();                              // 수신 처리 + keepalive. 자주 불러야 한다
  } else if (WiFi.status() == WL_CONNECTED && millis() - lastTry >= 3000) {
    lastTry = millis();
    // 유언(LWT): 내가 말없이 죽으면 브로커가 link=0(retained)을 대신 발행
    if (mqtt.connect("modem-" STATION, BASE "link", 0, true, "0")) {
      mqtt.publish(BASE "link", "1", true);   // retained
      mqtt.subscribe(BASE "cmd");
      mqtt.subscribe(BASE "state");           // retained라 구독 즉시 현재 상태가 온다 → $S가 보드로 간다
      mqtt.subscribe(BASE "test");
      up = true;
      DBG("# MQTT 연결\n");
    } else DBG("# MQTT 실패 rc=%d\n", mqtt.state());
  }
  if (up != wasUp || (LINK_REPEAT_MS && millis() - lastLink >= LINK_REPEAT_MS)) {
    wasUp = up; lastLink = millis();
    sendToBoard(up ? "L,up=1" : "L,up=0");
  }
}

void setup() {
  Serial.begin(115200);
  Serial2.setRxBufferSize(1024);              // begin 전에. MQTT 재접속으로 잠깐 막혀도 안 넘치게
  Serial2.begin(115200, SERIAL_8N1, PIN_RX2, PIN_TX2);
  WiFi.mode(WIFI_STA);
  WiFi.setSleep(false);                       // 절전 끔: 응답 지연 줄임
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  mqtt.setServer(MQTT_HOST, MQTT_PORT);
  mqtt.setCallback(onMqtt);
  mqtt.setBufferSize(MQTT_BUF);
  mqtt.setKeepAlive(4);                       // 전원이 뽑히면 약 1.5배(6초쯤) 뒤 브로커가 link=0을 낸다
  mqtt.setSocketTimeout(3);                   // 브로커가 없을 때 connect()가 막히는 시간 줄임
  DBG("\n# modem %s 시작 (TEST_MODE=%d)\n", STATION, TEST_MODE);
}

void loop() {
  pollBoard();
  serviceWifi();
  serviceMqtt();
}

// tag.ino — 스마트태그 뼈대 (Arduino-ESP32 3.x / PubSubClient 2.8 / ArduinoJson 7)
#include <WiFi.h>
#include <PubSubClient.h>
#include <ArduinoJson.h>
#include <Preferences.h>
#include "secrets.h"

#define TAG_NAME "tag1"
#define BASE     "factory/tag/" TAG_NAME "/"
#define PIN_LED  2               // NodeMCU-32S 내장 LED
#define PIN_BTN  0               // 보드의 BOOT 버튼 (부팅 후에는 일반 버튼으로 쓸 수 있다). 실물에선 교체
#define LOG_N    16              // 최근 N건만 보관 (링 로그)

struct Rec { uint32_t seq; uint16_t id; char body[16]; char p[4]; char r[4]; };

WiFiClient   net;
PubSubClient mqtt(net);
Preferences  nv;
uint32_t lastSeq = 0, msgN = 0;
uint8_t  head = 0, count = 0;    // head = 다음에 쓸 칸
uint16_t lastId = 0;

// ───── 상태 기계 + LED 패턴 (100ms × 16칸 비트 패턴, delay 없음) ─────
enum State { ST_OFFLINE, ST_IDLE, ST_WROTE, ST_ERROR };
const uint16_t PATTERN[] = { 0x5555,   // OFFLINE: 빠른 깜빡임
                             0x0001,   // IDLE: 1.6초마다 짧게 한 번
                             0xFFFF,   // WROTE: 켜짐
                             0x0005 }; // ERROR: 두 번 깜빡
State state = ST_OFFLINE;
uint32_t stateSince = 0;
void setState(State s) { state = s; stateSince = millis(); }
void serviceLed() { digitalWrite(PIN_LED, (PATTERN[state] >> ((millis() / 100) % 16)) & 1); }

// ───── 플래시 링 로그 (NVS) ─────
void logLoad() {
  nv.begin("tag", false);                     // 이름공간 "tag", 읽기/쓰기
  head = nv.getUChar("head", 0); count = nv.getUChar("cnt", 0); lastSeq = nv.getUInt("seq", 0);
}
void logAdd(const Rec &r) {
  char key[8]; snprintf(key, sizeof key, "r%u", (unsigned)head);
  nv.putBytes(key, &r, sizeof r);             // 기록 먼저, 위치/seq는 그 다음 (중간에 꺼져도 재전송으로 복구)
  head = (head + 1) % LOG_N; if (count < LOG_N) count++;
  nv.putUChar("head", head); nv.putUChar("cnt", count); nv.putUInt("seq", r.seq);
  lastSeq = r.seq;
}
void logDump() {                              // 오래된 것부터 USB로 출력
  for (uint8_t i = 0; i < count; i++) {
    char key[8]; snprintf(key, sizeof key, "r%u", (unsigned)((head + LOG_N - count + i) % LOG_N));
    Rec r;
    if (nv.getBytes(key, &r, sizeof r) == sizeof r)
      Serial.printf("# seq=%lu id=%u body=%s p=%s r=%s\n", (unsigned long)r.seq, (unsigned)r.id, r.body, r.p, r.r);
  }
}

void answer(uint16_t id) {                    // 명령에 대한 답: {"re":5,"ok":1} (신고 번호 없음, 다시 보내지 않는다)
  char out[40];
  snprintf(out, sizeof out, "{\"re\":%u,\"ok\":1}", (unsigned)id);
  mqtt.publish(BASE "report", out);
}
void report(const char *kind) {               // 태그가 먼저 알리는 신고: {"n":3,"k":"BTN"}
  char out[48];
  msgN = msgN % 255 + 1;                      // 신고 번호는 1~255를 돌려 쓴다
  snprintf(out, sizeof out, "{\"n\":%lu,\"k\":\"%s\"}", (unsigned long)msgN, kind);
  mqtt.publish(BASE "report", out);
}

// ───── 명령 수신 ─────
void onMqtt(char *topic, byte *payload, unsigned int len) {
  if (strcmp(topic, BASE "cmd") != 0) return;
  JsonDocument doc;
  if (deserializeJson(doc, (const char *)payload, len)) { setState(ST_ERROR); return; }
  const char *what = doc["do"] | "";          // 키가 없으면 "" (기본값)
  uint16_t id = doc["id"] | 0;
  if (strcmp(what, "WRITE") == 0) {
    Rec r = {};
    r.seq = doc["seq"] | 0u; r.id = id;
    strlcpy(r.body, doc["body"] | "", sizeof r.body);
    strlcpy(r.p, doc["p"] | "", sizeof r.p);
    strlcpy(r.r, doc["r"] | "", sizeof r.r);
    if (count == 0 || r.seq != lastSeq) logAdd(r);   // 같은 seq 재전송이면 저장은 건너뛰고 답만 다시
    lastId = id;
    answer(id);                               // payload는 이미 다 복사했으므로 여기서 publish해도 안전
    setState(ST_WROTE);
  }
}

// ───── 버튼: 짧게/길게 (30ms 디바운스, 눌림 = LOW) ─────
void onShort() { if (mqtt.connected()) report("BTN"); }           // 예시 동작 — 팀 규격으로 교체
void onLong()  { logDump(); }                                     // 예시 동작 — 팀 규격으로 교체
void pollButton() {
  static bool stable = HIGH, last = HIGH, longDone = false;
  static uint32_t tEdge = 0, tDown = 0;
  bool now = digitalRead(PIN_BTN);
  if (now != last) { last = now; tEdge = millis(); }
  if (now != stable && millis() - tEdge >= 30) {
    stable = now;
    if (stable == LOW) { tDown = millis(); longDone = false; }
    else if (!longDone) onShort();            // 길게 누르기가 이미 처리됐으면 뗄 때는 무시
  }
  if (stable == LOW && !longDone && millis() - tDown >= 1500) { longDone = true; onLong(); }
}

// ───── 연결 유지 ─────
void serviceNet() {
  static uint32_t lastWifi = 0, lastMqtt = 0;
  if (WiFi.status() != WL_CONNECTED) {
    if (millis() - lastWifi >= 15000) { lastWifi = millis(); WiFi.disconnect(); WiFi.begin(WIFI_SSID, WIFI_PASS); }
  } else if (!mqtt.connected() && millis() - lastMqtt >= 3000) {
    lastMqtt = millis();
    if (mqtt.connect("tag-" TAG_NAME, BASE "link", 0, true, "0")) {
      mqtt.publish(BASE "link", "1", true);
      mqtt.subscribe(BASE "cmd");
    } else Serial.printf("# MQTT 실패 rc=%d\n", mqtt.state());
  }
  if (mqtt.connected()) mqtt.loop();

  // 상태 전이
  if (!mqtt.connected()) { if (state != ST_OFFLINE) setState(ST_OFFLINE); }
  else if (state == ST_OFFLINE) setState(ST_IDLE);
  else if ((state == ST_WROTE || state == ST_ERROR) && millis() - stateSince >= 2000) setState(ST_IDLE);
}

void setup() {
  Serial.begin(115200);
  pinMode(PIN_LED, OUTPUT);
  pinMode(PIN_BTN, INPUT_PULLUP);
  logLoad();
  Serial.printf("\n# tag %s 시작, 저장 %u건, lastSeq=%lu\n", TAG_NAME, (unsigned)count, (unsigned long)lastSeq);
  WiFi.mode(WIFI_STA);
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  mqtt.setServer(MQTT_HOST, MQTT_PORT);
  mqtt.setCallback(onMqtt);
  mqtt.setBufferSize(512);
  mqtt.setKeepAlive(4);
  mqtt.setSocketTimeout(3);
}

void loop() {
  serviceNet();
  pollButton();
  serviceLed();
}

#include <stdio.h>
#include <string.h>
#include <stdint.h>
#include <stdlib.h>
/* body = '$'와 '*' 사이 전부 (종류 글자 포함) */
uint8_t frame_xor(const char *body, size_t len) {
    uint8_t cs = 0;
    while (len--) cs ^= (uint8_t)*body++;
    return cs;
}
/* out에 "$body*HH\n" 작성. 반환: 길이, 공간 부족이면 0 */
int frame_build(char *out, size_t cap, const char *body) {
    int n = snprintf(out, cap, "$%s*%02X\n", body, frame_xor(body, strlen(body)));
    return (n > 0 && (size_t)n < cap) ? n : 0;
}
/* line = "$....*HH" (개행 제거된 상태). 맞으면 1, body 시작/길이를 돌려줌 */
int frame_check(const char *line, size_t len, const char **body, size_t *blen) {
    if (len < 5 || line[0] != '$' || line[len - 3] != '*') return 0;
    char hex[3] = { line[len - 2], line[len - 1], 0 };
    char *end;
    unsigned long want = strtoul(hex, &end, 16);
    if (end != hex + 2) return 0;
    if (frame_xor(line + 1, len - 4) != (uint8_t)want) return 0;
    *body = line + 1; *blen = len - 4;
    return 1;
}

from functools import reduce
def frame(body: str) -> str:
    """body = 종류 글자 + 내용 (예: 'C,re=42,ok=1')"""
    cs = reduce(lambda a, b: a ^ b, body.encode(), 0)
    return f"${body}*{cs:02X}"
def check(line: str) -> bool:
    line = line.strip()
    if not line.startswith("$") or len(line) < 5 or line[-3] != "*": return False
    try: return frame(line[1:-3]).upper() == line.upper()
    except ValueError: return False

모뎀이 지키는 규칙

  • 줄은 240자까지. 넘으면 다음 줄바꿈까지 통째로 버립니다. 검사값이 틀려도 버립니다.
  • 브로커에 붙어 있지 않을 때 보드에서 온 줄은 버립니다. 다시 보내는 것은 보드의 일입니다.
  • 2초마다 보드에 연결 상태를 알립니다: $L,up=1*69 또는 $L,up=0*68.
  • '지금 상태'의 차체 번호(body)는 보드에 넘기지 않습니다. 보드는 몰라도 됩니다.
