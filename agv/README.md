# AGV 주행 코드

AGV(JETANK)가 매트의 검은 선을 반시계로 돈다. **몸통 정중앙이 검은 선 위로** 가는 것이 목표다(모서리에서도).
"언제 서나 / 언제 출발하나"는 `conditions.py` 한 곳에 있어서, 나중에 그 함수만 MQTT("태그 읽음" / "작업 완료")로 바꾼다.

주행 방식은 **상황별 주행 하나**다(`situ.py`). 이전 방식들(화면 가운데 맞춤, 학습 모델, 정해 둔 호 돌기, 선 기억)은 2026-11-26에 코드에서 지웠다. 왜 버렸는지는 `진행기록_1125.md`, `진행기록_1126.md`에 있다.

## 상황별 주행이 하는 일

카메라는 차체 중심보다 13~25cm 앞 바닥만 본다. 선을 기억하지 않고, 지금 보이는 것으로만 판단한다. 회전은 시간·각도가 아니라 카메라가 끝낸다.

| 상태 | 언제 | 무엇을 하나 |
|---|---|---|
| LINE | 선이 보임 | 선의 옆 오차 e와 방향 ψ로 조향. 조금 틀어지면 달리며 꺾고, 10° 넘게 틀어지면 서서 제자리 회전(ALIGN)으로 먼저 맞춤 |
| APP | 앞쪽 선이 왼쪽으로 휨(3장 연속) | 속도를 줄여 직진(0.25) |
| COR | 화면 맨 아랫줄의 선이 왼쪽 7cm에 닿음 | 1cm 더 가서 제자리 좌회전 → 선이 6cm 안으로 들어오면 직진 → 반복. 나가는 곧은 선 위에 오면 방향을 맞추고 LINE으로 |
| LOST | 선을 놓침 | 모서리가 올 구간이면 왼쪽으로, 색 구역이 선을 가린 것이면 곧게, 아니면 마지막으로 선이 있던 쪽으로 돌며 찾음 |

- **갈림길**은 구간 규칙으로 고른다(`config.json` branch.rules): 빨강→노랑 = 왼쪽, 노랑 위 X자 = 직진, 노랑 뒤 ~ 주황 = 오른쪽, 초록·보라 = 오른쪽.
- **모서리**는 맵 순서상 올 구간(목표가 orange·green·blue·yellow)에서 구간당 한 번만 시작한다.
- **핸들 방식**(`ctrl.cor_steer*`): 모서리 판단은 그대로 두고 모서리 안의 모터 값만 바꾼다. 첫 회전 뒤부터 안쪽 궤도는 살짝 뒤로, 바깥은 세게 앞으로 돌려 가면서 돈다. 지금은 목표가 blue인 모서리(보라→파랑)에만 켜져 있다.
- 설계와 근거(사진 검증, 계산): `설계안_1126_상황별주행.md`

## 배운 것

- 같은 코드인데 될 때도 있고 안 될 때도 있었다 → **운이었다.** 한 자리에서 몇 번 잘 된 것으로 믿지 않는다. 출발 자리를 바꿔 가며 본다.
- 문제의 많은 수가 "선 추적기가 틀린 갈래에 붙은 채 규칙이 바뀌는 것"이었다(빨강→노랑 끝, 노랑 X자 끝).
- 혼자 숫자를 짐작으로 바꾸면 나빠졌다. 기록·사진으로 원인을 찾고, 여럿이 동시에 보고 정한 한 가지만 바꾼다.
- 시험 도구의 한계: 사진 다시 넣기(`replay.py`)는 11-27 주행에서 시간이 어긋난다. 대신 사진을 추적기에 직접 넣거나 기록의 값을 판정에 넣어 비교했다.

## 쓰는 법

- 현장: `run_agv.ipynb`. `서기 = 통과만`, `막 떠난 구역`을 고르고 `출발`. `달리며 사진 저장`을 켜면 `logs/frames_*/`에 사진이 남는다.
- 기록 열(`logs/run_*.csv`): `mode`(LINE, ALIGN, LINE_X, APP, COR_GO/EXT/TURN, HOLD, LOST), `e_cm`·`psi_deg`(선의 옆 오차·방향), `yb`(아랫줄 선 위치 cm), `s_deg`(직선 조향 오차 °), `cor`(모서리 단계/회전 횟수), `left`·`right`(궤도 명령).
- 매트 없이: `python3 tools/sim_situ.py`(numpy만 필요) / `python3 replay.py <사진 폴더> --dt 0.05`, `python3 tools/test_fsm.py`(OpenCV 필요).

## 알아 둘 숫자 (실측)

- 카메라 224 × 224, 서보 5번 50°로 고정.
- 직진 0.40 ≈ 5.8cm/s. 궤도 값 0.05~0.17은 돌 때 멈춘다(0, 0.18 이상, −0.25 이하만 쓴다).
- 제자리 회전 ±0.35: 13~17°/s. 달리며 꺾기(0.25/0.55): 8~11°/s뿐.
- 렌즈 휨을 펴지 않아서 화면 가장자리의 각도·거리는 부정확하다(반지름 14cm 호가 19~23cm로 보임). 그래서 모서리는 화면 맨 아랫줄만 쓴다.
- 배터리와 빛에 따라 달라진다. 저녁 빛에서는 선과 매트의 밝기 차이가 줄었다(`진행기록_1126.md`).
